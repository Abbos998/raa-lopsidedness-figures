# A Statistical Analysis of Lopsidedness in Disk Galaxies — Figures & Code

Analysis code and figure-generation scripts for the paper:

> **A. U. Omonov, K. T. Mirtadjieva, S. N. Nuritdinov, D. Dottorini** (2026),
> *"A Statistical Analysis of Lopsidedness in Disk Galaxies"*,
> Research in Astronomy and Astrophysics (RAA), in press.

All 8 figures are regenerated from the **deduplicated** VII/296 Table 2.

## Sample sizes (deduplicated)

| Quantity | Value |
|---|---|
| Catalogue entries (raw) | 683 |
| Duplicate galaxies | 71 (resulting in 77 extra entries) |
| **Unique galaxies total** | **606** |
| With valid A1 (clean) | **442** |
| With valid A2 (clean) | **302** |
| With both A1 & A2 | **302** |
| Stellar-mass cross-matched subsample (A1 + M*) | **246** |

## Requirements

Python >= 3.8 with:

```
numpy >= 1.20
scipy >= 1.7
pandas >= 1.3
matplotlib >= 3.5
statsmodels >= 0.13
```

Install with:

```bash
pip install -r requirements.txt
```

## How to regenerate all figures

```bash
cd scripts
bash run_all.sh
```

Or any individual figure:

```bash
cd scripts
python3 fig3_coupling.py
```

Output PDFs and PNGs are written to `../figures/`.

## Key results summary (after deduplication)

### Fig 1 — Distributions
- A1: N = 442, median = 0.117, mean = 0.157
- A2: N = 302, median = 0.114, mean = 0.153

### Fig 2 — Distribution fits
- A1: log-normal mu = -2.195, sigma = 0.866, KS D = 0.046
- A2: log-normal mu = -2.274, sigma = 0.916, KS D = 0.048
- Both strongly prefer log-normal over Rayleigh (D ~ 0.25) and exponential (D ~ 0.10)

### Fig 3 — A1-A2 coupling (N = 302)
- Pearson r = +0.274
- Spearman rho = +0.501 (p < 10^-19)
- Linear fit: **A2 = 0.29 A1 + 0.11**

### Fig 4 — Morphology (T-type)
- A1 vs T: Kendall tau = +0.234 (p ~ 10^-12) — monotonic rise
- A2 vs T: Kendall tau = +0.044 (p = 0.26) — no significant trend
- Median A1: E/S0 ~ 0.07 -> Sm/Im ~ 0.37 (factor ~ 5)

### Fig 5 — Physical parameters
- A1 vs V_rot: Pearson r = -0.332, Spearman rho = -0.432 (p ~ 10^-19)
- A1 vs M_B (clipped): Pearson r = +0.212, Spearman rho = +0.226
- A1 vs sigma_c, z: non-significant

### Fig 6 — A2/A1 ratio
- Median A2/A1 = 0.90; 44.7% have A2 > A1

### Fig 7 — Stellar-mass subsample
- N = 246, Pearson r = -0.383, Spearman rho = -0.395 (p ~ 10^-10)
- Monotonic decline from ~ 0.29 at log M* ~ 9.3 to ~ 0.07 at log M* ~ 10.75

### Fig 8 — TNG50 comparison
- KS D = 0.292 (p ~ 10^-15), median ratio obs/TNG50 = 1.44x
- Spearman rho: obs = -0.395 vs TNG50 = -0.445 (consistent in sign and magnitude)
- Qualitative agreement; absolute amplitude offset consistent with heterogeneous target selection

## Data sources

- `table1.dat`, `table2_original.dat`, `ReadMe`: VII/296 catalog
  (Nuritdinov, Mirtadjieva & Omonov 2024), accessed via CDS/VizieR.
- `table2_dedup.dat`: Deduplicated version of `table2_original.dat` produced by the
  canonicalisation procedure described in Section 2 of the paper.
- `catalog_TNG50.csv`: Generated by the **TNGGalaxyLab** pipeline
  (<https://github.com/Abbos998/TNGGalaxyLab>) from IllustrisTNG50-1 snapshot 99.
  The IllustrisTNG data are released under the CC-BY-4.0 license
  (Nelson et al. 2019; Pillepich et al. 2019).
